این پوشه محتوای تولیدشده می‌گیرد و در gitignore است:

- `bundle.json` — خروجی `node src/cli.js bundle ...` (پیکربندی آمادهٔ هر پله + رتبه‌بندی + پیوندهای اشتراک)
- `profile.json` — پروفایل امضاشدهٔ گره‌ها (برای verify کردن امضا در زمان اجرا)

به مقصد ناشناخته نمی‌فرستد.
